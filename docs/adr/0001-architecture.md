# ADR 0001: Один процесс и стандартный HTTP proxy

Статус: принято для v0.1.

Контекст: проект начинался как спецификация. Нужен проверяемый путь от декларативного маршрута до HTTP ответа.

Решение: один Go-процесс, `net/http`, `httputil.ReverseProxy`, статическая конфигурация. Внутренние пакеты разделяют загрузку, выбор маршрута и serving; интерфейсы добавляются только при появлении второго потребителя.

Последствия: малая база зависимостей и тестируемая вертикаль. Балансировка, control plane и reload требуют отдельного проектирования и не имитируются пустыми пакетами.
